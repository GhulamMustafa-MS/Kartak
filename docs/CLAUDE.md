# docs/

Project documentation. Each fact has exactly one home here (root CLAUDE.md section 3); other files link to it.
Not published by Vercel (`.vercelignore`).

| File | Purpose | Update when |
|---|---|---|
| `progress.md` | The only place for status: START HERE (under 40 lines), open items, dated log, archive. Read first in a new chat | after every piece of work |
| `plan.md` | The product: problem, users, exam facts, what is built, business model, roadmap, competition, how to add a question / language / change the timer or password | when the plan or a how-to changes |
| `design_decisions.md` | The only place for decisions: dated index (who decided) and entries with the reason and the alternative rejected | when a decision is made |
| `architecture.md` | How the pieces fit: diagram, addresses, Vercel and Neon IDs, data flow | when hosting, addresses or data flow change |
| `api.md` | Every endpoint: method, path, file, caller, request, response, status codes, rules | when an endpoint changes |
| `handbook.md` | The only place for the official handbook's syllabus (chapters 1-13) and every food-safety number the questions use (D22). The handbook PDF itself is never stored in the repo | when a question needs a fact not listed, or a number is corrected |
| `summary.md` | Problems met and how they were solved; limitations and risks | when a problem or limitation is found |
